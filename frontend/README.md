# Ledgerly Frontend (React + Vite)

This frontend runs on React + Vite and talks to the Ledgerly backend API.

## Environment

Create/update `.env`:

```bash
VITE_API_URL=http://127.0.0.1:8000
```

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:5173`.

## Build

```bash
npm run build
npm run preview
```
